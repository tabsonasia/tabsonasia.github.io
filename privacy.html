Privacy Policy

Effective date: 2 October 2026

What this covers

This policy covers the "Tabs on Asia publisher" (the "tool") and this website. The tool is a private tool run by the operator of the Tabs on Asia channel. It uploads the channel's own videos to the channel's own YouTube, TikTok and Instagram accounts.

How the tool works

The tool uses the official APIs of each platform: the YouTube Data API, the TikTok Content Posting API and Login Kit, and the Instagram API with Instagram Login.

The tool is not offered to the public. No other users sign in to it. Only the channel's operator connects the channel's own accounts.

What the tool accesses

  • Basic profile information of the channel's own accounts (account ID and name). This confirms that the tool is posting to the right account.
  • Permission to upload and publish videos to those accounts.

Viewers

The tool collects no data from viewers. This website has no sign-in, no forms, no cookies, no analytics and no trackers. Viewers never grant the tool any access, so there is nothing for a viewer to revoke.

Storage and sharing

Access tokens are stored locally on the operator's computer. They are never shared or sold. They are not used for advertising. The only other records kept are of the channel's own uploads (such as video IDs and upload times).

Retention and revoking access

Tokens are kept until the operator revokes them. The operator can revoke access at any time in the account settings of Google, TikTok or Meta.

Google API Services User Data Policy

The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data from the YouTube API is used only to provide the upload feature for the channel's own videos. It is not transferred to others, not used for advertising, and not read by people except as needed to operate the tool.
